## 一、本週市場情緒研判：**中性偏多，「模型公司主導 ASIC + NVIDIA Vera Rubin 啟動」結構性高檔分歧震盪**

上週我們提示「記憶體牆主戰場 + 通路化加速 + 漲價反噬 + 反壟斷」高檔分歧震盪結構。本週 DIGITIMES 多則重磅報導確認市場進入「**模型公司自研 ASIC（Anthropic→三星 2 奈米）+ 四方 ASIC 卡位戰（Google / Anthropic / 聯發科 / AWS）+ NVIDIA Vera Rubin 啟動 + 雲端新型態結盟 + 記憶體漲價擴散到通用 DRAM + 光通訊 / 玻璃基板 / CPO 全鏈擴產 + SEMI 政治示警 + 反壟斷罰款定讞**」的高檔分歧震盪新階段——多頭動能仍在，但 ASIC 世代交替的長期競爭壓力同步升溫。

**1. 模型公司自研 ASIC 掀世代交替：Anthropic 投三星 2 奈米、阿里禁用 Claude Code、ASIC 進入『模型公司主導』世代。** DIGITIMES 2026/07/03 揭露「**Anthropic 傳相中三星 2 奈米代工、自研 ASIC 戰略擺脫外部採購依賴**」——這是 AI 模型公司首次明確揭露「自建晶片產線 + 選擇非台積電代工廠」的雙重訊號。**Anthropic 從 OpenAI 自研晶片啟動以來，正式加入「模型公司自研 ASIC」賽局，並選擇三星 2 奈米代工而非台積電**，這個決策的產業意涵：（a）模型公司從「買 GPU + 委託 CSP 設計 ASIC」轉向「自建晶片產線」；（b）三星 2 奈米製程獲得首個 AI 模型公司的明確設計定案，是三星代工業務的重大突破；（c）台積電在 ASIC 領域的市占率可能面臨長期結構性競爭壓力。**DIGITIMES 2026/07/04 週末新聞速寫揭露阿里將禁用 Claude Code**——阿里以自家通義千問 + Qwen Code 取代 Claude Code，這是中國 CSP 對 Anthropic 的明確抵制，呼應上週 Android 反壟斷罰款 + Anthropic 在中國市場的監管壓力。**Anthropic 自研 ASIC + 阿里禁用 Claude Code + OpenAI 自研晶片（前週揭露）**——AI 模型的「自研晶片 + 自家生態」雙閉環策略已成形。**對台股的意義**：**台積電（2330）**短期內仍是先進製程主導者，但 ASIC 客戶的世代交替（CSP → 模型公司 + 部分訂單流向三星）對長期市占率形成結構性壓力；**三星代工**則是直接受惠者；**IC 設計服務鏈**（創意 3443、世芯-KY 3661、M31 6643、智原 3035）若能切入 Anthropic 自研晶片供應鏈則受惠，但短期 Anthropic 已選定三星代工、未必立即需要台系設計服務。

**2. 四方 ASIC 卡位戰白熱化：聯發科左手 TPU、右手 ASIC 第二家客戶 vs 高通手握 Meta / 微軟 / 字節跳動 vs Google 持續深化合作 vs AWS ASIC 量產加速。** DIGITIMES 2026/07/02 揭露「**聯發科左手猛攻 TPU、右手開拓 ASIC『第二家客戶』**」的完整內文：『高通眼下看來手握 Meta、微軟（Microsoft）甚至是字節跳動的關鍵大客戶，但外界普遍認為，和 Google 持續深化合作，並且有機會確定第二個客戶合作的聯發科，其實並沒有落於下風。半導體供應鏈業界人士直言，以目前各大雲端服務業者（CSP）對於 AI 資料中心與 ASIC 產品的拉貨預期以及迭代的進度，Google 直到現在仍是發展狀況最好，態度也最積極的大客戶。當然這並不代表其他 CSP 业者的訂單不具規模，或是可能出現延遲，而是意味著，能拿到 Google 訂單的話，比較能夠確保其為營運帶來的正面效果，只要量產時間表出爐，基本上就能確定該年度可以多賺到多少，且都具備一定的規模。』這段實證訊號極為關鍵：**聯發科與 Google 持續深化合作 + 有機會確定第二個客戶合作 = 聯發科在 ASIC 領域已從『高通之後的追隨者』轉為『Google TPU 的核心供應商 + 第二家客戶的潛在新主』**。DIGITIMES 2026/07/02 揭露「**《新聞聚焦》AWS ASIC 伺服器量產加速、台廠迎下半年新動能**」、DIGITIMES 2026/06/30 揭露「**GPU、ASIC 新平台齊放量、伺服器 ODM 迎 2H26 強勁出貨潮**」——AWS ASIC 量產 + GPU 平台放量雙線並進，台廠下半年出貨動能明確。**對台股的意義**：**聯發科（2454）**直接受惠於 TPU 合作 + ASIC 第二家客戶拓展；**創意（3443）**作為 AWS、Google TPU、博通、Marvell 的 IC 設計服務夥伴同步受惠；**世芯-KY（3661）**受惠於 AWS、Google、博通委外設計鏈；**M31（6643）、智原（3035）**IP 與 ASIC 服務同步受惠；**鴻海（2317）、廣達（2382）、英業達（2356）、緯創（3231）、緯穎（6669）、技嘉（2376）**ODM 大廠同步受惠於 GPU+ASIC 新平台放量；**奇鋐（3017）、雙鴻（3324）、川湖（2059）、南俊國際**散熱 / 滑軌業務受惠於 ASIC 伺服器量產。

**3. NVIDIA 雲端新型態結盟 + Vera Rubin 3Q26 起飛：GPU 陣營鞏固 + 雲端基礎設施整合。** DIGITIMES 2026/07/03 揭露「**NVIDIA 推新型態雲端基礎設施結盟、回應 AI 算力需求激增**」+ DIGITIMES 2026/06/25 揭露「**NVIDIA 催貨力道強勁、Vera Rubin 動能 3Q26 起飛**」——NVIDIA 從「賣 GPU」轉向「賣整合雲端基礎設施」+ Vera Rubin 平台 3Q26 正式啟動，這是 GPU 陣營對「ASIC 自研浪潮」的回應。**Vera Rubin 是 NVIDIA 下一代 GPU 平台，3Q26 起飛意味著台積電 CoWoS / CoPoS 產能將進入新一輪擴張週期**。**對台股的意義**：**台積電（2330）**CoWoS / CoPoS 產能受惠於 Vera Rubin 量產；**弘塑（3131）、辛耘（3583）、志聖（2467）、家登（3680）**先進封裝設備廠同步受惠；**欣興（3037）、景碩（3189）、南亞電路板（8046）**ABF 載板廠同步受惠；**奇鋐、雙鴻、邁科、訊凱國際**散熱業務受惠；**川湖、南俊國際**滑軌業務受惠；**Astera Labs 相關台廠**受惠於高速介面需求（Vera Rubin 採用 NVLink + 高速 SerDes）。

## 四、中期展望（3-6 個月）

### 模型公司自研 ASIC 浪潮成形：CSP 主導 → 模型公司主導的世代交替

**核心觀察**：AI 模型公司（OpenAI、Anthropic、可能的 Mistral / Cohere / xAI）正從「買 GPU / 委託 CSP 設計 ASIC」轉向「自建晶片產線 + 選擇代工廠」。這個世代交替對台股的影響：（a）台積電在 ASIC 領域的市占率可能面臨長期結構性壓力（三星 2 奈米已獲 Anthropic 定案）；（b）IC 設計服務鏈（創意、世芯-KY、M31、智原）若能切入模型公司自研晶片供應鏈則受惠；（c）聯發科、高通等 IC 設計大廠的 ASIC 卡位戰將持續白熱化。

### NVIDIA Vera Rubin 啟動 + 雲端新型態結盟：GPU 陣營鞏固

**核心觀察**：NVIDIA Vera Rubin 3Q26 起飛 + 新型態雲端基礎設施結盟 = GPU 陣營對「ASIC 自研浪潮」的回應。Vera Rubin 量產將帶動 CoWoS / CoPoS 產能進入新一輪擴張週期，台積電、先進封裝設備廠、ABF 載板廠、散熱 / 滑軌 / 高速介面廠同步受惠。

### 記憶體漲價擴散到通用 DRAM + SEMI 政治示警：記憶體供應鏈政治化

**核心觀察**：記憶體漲價從 HBM 擴散到標準型 DRAM + SEMI 致函川普示警 = 記憶體供應鏈已從「市場供需」進入「政治化」階段。南亞科、華邦電、旺宏等台系記憶體廠短期受惠於 DRAM 漲價循環，但長期須注意 SEMI 政治示警後美國是否調整在地化政策。

### 光通訊 / 玻璃基板 / CPO 全鏈擴產：AI 封裝新時代

**核心觀察**：京東方 + 住友 + 三星 + 上詮 / 聯亞 / IET-KY / 全新 / 訊芯-KY 全鏈擴產 = 光通訊 / 玻璃基板 / CPO 已成為 AI 封裝的核心戰場。台積電 CoPoS 玻璃基板計畫 + 台系光通訊廠將是這一輪 AI 封裝新時代的核心受惠者。

## 五、長期趨勢（半年～一年以上）

### AI 服務商業模式從「賣算力」轉向「賣整合」

**核心觀察**：AWS FDE + 微軟 Frontier + 營邦 NVIDIA + VAST Data + NVIDIA 雲端新型態結盟 = AI 服務商業模式已從「賣 API（按 token 計價）」轉向「賣整合（FDE + 儲存伺服器 + 通路）」。這個轉變對台股的影響：ODM 大廠（鴻海、廣達、英業達、緯創、緯穎）+ 散熱 / 滑軌 / 高速介面廠 + AI 服務整合商將成為下一個 10 年的核心受惠者。

### AI 模型「自研晶片 + 自家生態」雙閉環策略成形

**核心觀察**：OpenAI 自研晶片 + Anthropic 自研 ASIC + 阿里禁用 Claude Code = AI 模型的「自研晶片 + 自家生態」雙閉環策略成形。這對台股的影響：（a）台積電在 ASIC 領域的市占率可能面臨長期結構性競爭壓力；（b）IC 設計服務鏈需要重新思考客戶結構；（c）聯發科、高通等 IC 設計大廠的 ASIC 卡位戰將持續白熱化。

### AI 進入「企業導入 + 中期訓練 + FDE」三個新戰場

**核心觀察**：AI 競爭從「模型效能」轉向「企業導入 + 中期訓練 + FDE」三個新戰場。微軟 Frontier + FDE + Google AI 編碼部門重組 + Google ASI 路線圖 = AI 已進入「企業導入 + 垂直整合」的新時代。對台股的意義：AI 服務整合商 + 企業 AI 解決方案商將成為下一個成長動能。

## 結論

本週 DIGITIMES 2026/06/22-07/04 合計 25 則頭條，把上週「記憶體牆主戰場 + 通路化加速 + 漲價反噬 + 反壟斷」的六線並進高檔分歧格局，推進到「**模型公司自研 ASIC 掀世代交替（CSP 主導 → 模型公司主導）+ Anthropic 投三星 2 奈米 + 聯發科 TPU/ASIC 雙軌 + AWS ASIC 量產加速 + Google ASI 路線圖 + NVIDIA Vera Rubin 3Q26 起飛 + 雲端新型態結盟 + 記憶體漲價擴散到通用 DRAM + SEMI 政治示警 + 光通訊 / 玻璃基板 / CPO 全鏈擴產 + 反壟斷罰款定讞 + 川普不設 AI 監管**」的『**模型公司主導 ASIC 世代**』結構性高檔分歧新階段。

**對台股供應鏈的具體影響**：

1. **半導體（台積電 2330、三星代工）**：台積電短期內仍是先進製程主導者，但 ASIC 客戶世代交替對長期市占率形成結構性壓力；三星代工則直接受惠於 Anthropic 2 奈米定案。
2. **IC 設計服務鏈（創意 3443、世芯-KY 3661、M31 6643、智原 3035）**：同步受惠於 ASIC 浪潮，但須注意 Anthropic 投三星可能影響台系設計服務的客戶結構。
3. **AI 伺服器 ODM 與散熱（鴻海 2317、廣達 2382、緯創 3231、緯穎 6669、奇鋐 3017、雙鴻 3324）**：受惠於 ASIC + GPU 新平台齊放量 + AWS ASIC 量產加速。
4. **記憶體（南亞科 2408、華邦電 2344、旺宏 2337、群聯 8299、威剛 3260）**：直接受惠於 DRAM 漲價循環擴散到標準型 + HBM 高階封裝需求。
5. **光通訊與玻璃基板（上詮 3362、聯亞 3081、IET-KY 圖桋 4976、全新 2455、訊芯-KY 6451）**：直接受惠於光通訊 / 玻璃基板 / CPO 全鏈擴產。
6. **聯發科（2454）**：TPU 合作 + ASIC 第二家客戶拓展，仍是 Google TPU 的核心供應商。

**下行風險**：（a）Anthropic 投三星 2 奈米對台積電 ASIC 訂單的長期競爭壓力；（b）SEMI 示警記憶體晶片荒對全球供應鏈的政治風險；（c）蘋果微軟 NB / 手機漲價對終端需求的反噬；（d）三星電機 + 東友 AI 玻璃基板材料合資對台系玻璃基板廠的競爭壓力。
