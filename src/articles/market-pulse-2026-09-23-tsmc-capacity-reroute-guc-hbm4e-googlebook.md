上週「CSP 股權綁定 + 蘋果雙軌 + 治理國安化」格局,本週新增一個**結構性新訊號:台積電正式重分配 3/2 奈米產能,聯發科 TPU v9 同時採用 CoWoS-L 與 Intel EMIB-T 雙軌封裝**——DIGITIMES 2026/09/15 揭露這個微調的背後意義是把聯發科從「客戶之一」升級為「前後段封裝模式改變的決定者」。同期,**GUC 創意電子發表 16Gbps HBM4E IP(支援 TSMC SoIC-X)**,把 HBM4E 從記憶體廠規格戰推進到 IP 設計服務商規格戰;**Googlebook 5 機 10/4 美國上市**,聯發科與高通分單吃下 Arm NB 第二波生態。台灣半導體正式進入「**產能重分配 + IP 服務差異化 + Chromebook 後 Arm NB 統一**」三軸併進期。
## 一、本週市場情緒研判:中性偏多,新增「產能重分配 + IP 差異化 + Arm NB 統一」三軸

本週 25 則頭條在「CSP 股權綁定 + 蘋果雙軌 + 治理國安化」既有格局上,**新增 1 條結構訊號 + 2 條深化軸線**:

- **新訊號——台積 3/2 奈米正式重分配**:DIGITIMES 2026/09/15 揭露,**聯發科承接 Google TPU v9 後,該晶片同時用 CoWoS-L 與 Intel EMIB-T 雙封裝**,已**微調聯發科 3 奈米、2 奈米產能**。聯發科從「客戶之一」升級為「**產能配置觸發者**」。
- **深化——GUC HBM4E IP 落 SoIC-X**:DIGITIMES 2026/09/22 指出,**GUC HBM4E IP 提供 face-up 版本,整合 TSV + feedthrough power delivery**,搭配 proteanTecs 互連監測,把 HBM 從「記憶體廠規格戰」推進到「**IP 設計服務商規格戰**」。
- **深化——Googlebook 5 機 10/4 美國上市**:DIGITIMES 2026/09/23 揭露**首波宏碁、華碩、戴爾、HP、聯想 5 家,英特爾拿 3 家、高通 2 家、聯發科切入聯想另一款** ——Arm 陣營把 Googlebook 從教育版升級為「**主流 NB 第二波統一戰線**」。

**情緒判斷**:中性偏多。**台積產能重分配**打開聯發科等 ASIC 族群「客戶角色升級」紅利,但 3/2 奈米長約客戶排擠同步升級;**HBM4E IP** 鞏固台灣「記憶體廠 + IP 服務」雙位置,SK 海力士/三星垂直整合壓力同步;**Googlebook** 出貨動能 + 單價較低、毛利貢獻有限。
## 二、關鍵驅動因素

### 1. 台積 3/2 奈米產能重分配:聯發科 TPU v9 雙封裝觸發排程鬆動

DIGITIMES 2026/09/15《台積 3/2 奈米、CoWoS 仍吃緊 AWS、聯發科、TPU 產能配置有變》揭露本週最關鍵的產能結構變化。**聯發科承接 Google TPU v9 大單後,下一代 TPU 同時採用台積 CoWoS-L 與 Intel EMIB-T 雙封裝路徑** ——這是 Google TPU 史上首次「**前段用台積、後段用 Intel EMIB**」的混合封裝模式,前後段供應模式改變,**已微調聯發科 3 奈米、2 奈米產能安排**。

背後時序:台積 5/4 奈米自 2023 年以來稼動率維持滿載,**3 奈米同樣自量產以來成為 AMD、Intel、蘋果、博通、高通爭搶目標,已長達數年產能滿載**;**2 奈米在 2026 年 7 月由 AMD 代號「Venice」的 EPYC 伺服器 CPU 與 MI455X GPU 搶先採用,iPhone 新機 A20 Pro 晶片也於同月導入、迎來放量**。DIGITIMES 同步點出,**AWS、聯發科、TPU 三條線是當前產能最敏感的重配訊號** ——AWS 為客製 ASIC 推論端、聯發科承接 Google TPU 後段封裝變化需要 3 奈米+2 奈米同步鬆動、TPU 從 CoWoS 單軌改成 CoWoS-L + EMIB-T 雙軌帶動封測產線重配。

**核心訊號**:台積 3/2 奈米產能正式進入「**客戶角色反轉**」新階段 ——從「台積分配給客戶」變成「**客戶帶動台積重配**」,聯發科已經是被認證的排程觸發者。**對台股的意義**:聯發科、世芯、創意、智原等 ASIC 族群長期受惠(客戶排程升級 → IP 議價力升級 → 後段封測京元電、矽格、穎崴、精測同步吃單);**台積電**本身則因產能利用率持續滿載、長約客戶排擠白熱化,**短期單價紅利持續、長約客戶結構調整風險同步升級**。
### 2. GUC HBM4E IP 進入 SoIC-X 量產準備:HBM 戰場推進到 IP 服務商規格戰

DIGITIMES 2026/09/22《創意電子宣布推出採用 2 奈米製程 16Gbps HBM4E IP》揭露 HBM 戰場的下一階段。**為支援 3D SoIC 架構,GUC HBM4E IP 提供專為 TSMC SoIC-X 技術設計的 face-up 版本** ——該 IP **整合專用 Through-Silicon Vias(TSVs)**,以**支援訊號輸出與輸入,以及向上層晶片提供電源(feedthrough power delivery)**,為複雜的 3D 整合架構建立完整的連接路徑。

技術細節:GUC HBM4E IP **亦整合 proteanTecs 的互連監測技術**,大幅提升 PHY 測試與特性分析之可視性,並強化終端產品於實際運行時的效能與可靠度。**創意電子技術長 Igor Elkanovich 表示**:「HBM4E 在頻寬與系統層級效能方面,為新一代 AI 加速器帶來重大突破。透過整合我們的 face-up HBM、face-up UCIe 與 GLink-3D IP,GUC 提供完整的 3D SoIC 架構介面 IP 解決方案,使客戶能夠無縫整合 HBM、chiplet 與 3D 堆疊,並充分發揮最先進製程技術的效能。」

頭條交叉佐證:DIGITIMES 2026/09/22《三星擬擴產 4 奈米、新設 2 奈米產線 滿足 HBM4 需求、搶先布局 HBM5》同步顯示,**三星將擴 4 奈米產能、新設 2 奈米產線**,首要目標是**滿足 HBM4 客戶端需求,並搶先布局 HBM5** ——記憶體廠直接搶邏輯製程產能,代表 HBM 已從「記憶體廠賣顆粒」演進為「**邏輯製程與記憶體製程雙綁定**」。

**核心訊號**:HBM 戰場進入「**IP 服務差異化**」新階段。**對台股的意義**:**創意電子**直接受惠 IP 規格升級,**世芯、智原、M31** 同步受惠 IP 服務市場擴張;**南亞科、華邦電、旺宏** 為台系記憶體代表,雖未直接做 HBM 但承接 LPDDR/DDR5 中端需求;**台積電** 因 SoIC-X 先進封裝持續吃緊,長約紅利與單價紅利同步升級。
### 3. Googlebook 5 機 10/4 美國上市:Arm 陣營把 NB 統一戰線推進第二波

DIGITIMES 2026/09/23《聯發科、高通卡位 Googlebook Arm 雙雄通吃 NB、手機野心浮現》揭露 Googlebook 時程與分工。**Googlebook 結合 Android 與 ChromeOS 技術基礎,首波 5 款機種由宏碁、華碩、戴爾、惠普與聯想推出,2026 年 10 月 4 日起將於美國上市**。

分工結構:
- **英特爾**:拿下宏碁、華碩、聯想 3 款 GoogleBook
- **高通**:拿下戴爾、HP 2 款,**搭載第一代 X Elite(12 核心 CPU + 45 TOPS NPU)**
- **聯發科**:切入聯想**另一款** GoogleBook

DIGITIMES 指出,**聯發科供應鏈像是前段的台積電,以及日月光投控、京元電、矽格、穎崴、精測等封測夥伴,都可望助攻**。高通則同時強調 X Elite 全日續航、NPU 驅動的 AI 工具、Snapdragon Elite Gaming 高幀率與畫質功能,並讓 Android 手機與 GoogleBook 無縫跨裝置接續。

頭條交叉佐證:DIGITIMES 2026/09/22《Google 前 AI 負責人看好自動化學習循環 加速客製化晶片設計》顯示,**Google 前 AI 負責人 Jeff Dean 看好「自動化學習循環」(AutoML)加速客製化晶片設計** ——與本週 GUC HBM4E IP 客戶名單背後邏輯互相呼應;DIGITIMES 2026/09/21《DIGITIMES Today:華為、小米、蘋果折疊機各打不同牌 | 台灣團訪歐洽談先進封裝與矽光子》同步揭露台灣團赴歐洽談**先進封裝與矽光子**,代表 CoWoS-L/SoIC-X 與光通訊已進入跨國合作期。

**核心訊號**:Arm NB 統一戰線正式進入第二波。**對台股的意義**:**聯發科**直接受惠 Googlebook 出貨,前段台積 3/2 奈米產能、後段日月光投控、京元電、矽格、穎崴、精測同步受惠;**宏碁、華碩** 為 Googlebook 品牌端第一波主要受惠者;**Chromebook 升級路線**將逐步吃掉傳統 x86 教育版圖。
### 4. 記憶體中國「龍頭之爭」:長江存儲 vs 長鑫三期 2.5 萬片 vs 韓系 HBM 3 年差距

DIGITIMES 2026/09/22《記憶體大缺引發長存、長鑫「龍頭之爭」 專利戰一觸即發》與 2026/09/22《長鑫第五代 G5 平台投入量產 晶圓產出數量直追記憶體三雄》兩條揭露中國記憶體「雙龍頭」競爭白熱化。

**長江存儲(長存)端**:**以獨家混合鍵合架構 Xtacking 技術起家,並突破美方卡關半導體設備進口的限制,已完成到 294 層 3D NAND 產品開發**;**三星 2025 年更與長江存儲達成「專利許可協議」,從第 10 代 V-NAND(V10)開始,三星將採用長江存儲的專利技術進行生產** ——這是中國記憶體 IP 第一次被國際龍頭反向授權。**長江存儲三期計畫 2026 年底投產,初期規劃約 2.5 萬片 DRAM 產能,2027 年完成產能爬坡**。

**長鑫(長鑫存儲)端**:**長鑫第五代 G5 平台投入量產**,晶圓產出數量直追記憶體三雄;DIGITIMES 2026/09/22《中韓 HBM 差距剩 3 年? 長鑫追趕三星、SK 海力士虛實待驗》點出「**中韓 HBM 差距剩 3 年**」的市場說法。

頭條交叉佐證:DIGITIMES 2026/09/22《長江存儲緊咬美光專利戰 禁制令出招恐牽動歐洲車用及工控》揭露**長江存儲對美光啟動專利戰**,禁制令出招恐牽動歐洲車用及工控。

**核心訊號**:中國記憶體進入「**龍頭之爭 + 專利戰 + 反向授權三星**」三維深化期。**對台股的意義**:**南亞科、華邦電** 在消費型 DRAM 與利基型記憶體受惠中國新產能尚未完全釋放前的緊缺紅利;**旺宏、群聯** 為 NOR Flash 與 NAND 模組受惠專利戰的替代效應;**創意、世芯** 為記憶體相關 IP 服務受惠 HBM4E 規格戰擴張;**載板三雄** 欣興、景碩、南亞電路板為記憶體封裝載板同步受惠。
### 5. AI 眼鏡暴增 + 人形機器人 IPO 踩煞車:消費型 AI 雙軸分歧

DIGITIMES 2026/09/22《AI 眼鏡 1H26 出貨量暴增 263% 蘋果傳 2027 年推首款產品》與 2026/09/22《宇樹科技市值大跌 北京傳出手要求人形機器人 IPO 踩煞車》兩條顯示**AI 穿戴的兩端極端**:一邊是 AI 眼鏡出貨暴增,一邊是人形機器人 IPO 被監管踩煞車。

**AI 眼鏡端**:**1H26 出貨量年增 263%**,**蘋果傳將於 2027 年推出首款 AI 眼鏡產品**,直接切入消費市場;**DIGITIMES 2026/09/23《AI 眼鏡「由繁化簡」 Meta Luna 傳捨相機兼顧輕量與隱私》**揭露 Meta Luna 從主打相機走向「輕量 + 隱私」路線 ——AI 眼鏡進入「**硬體精簡 + 軟體增益 + 隱私深化**」三軸。DIGITIMES 2026/09/22《百鏡大戰下的差異化邏輯 字節跳動建構供應鏈管理大軍》與《中國光學強勢進攻 紅色供應鏈力造智慧眼鏡大浪》同步顯示**字節跳動、紅色供應鏈、杭州第七龍 Rokid 靈伴科技** 同時進場。

**人形機器人端**:**宇樹科技市值大跌,北京傳出手要求人形機器人 IPO 踩煞車** ——中國監管開始對「**機器人 IPO 過熱**」進行窗口指導。同時 DIGITIMES 2026/09/23《日本產官攜手百家大廠 引進工具機共通 ID 衝刺實體 AI》揭露**日本產官學合作,百家工具機大廠引進共通 ID 衝刺實體 AI**;DIGITIMES 2026/09/23《人形機器人拚精細操作 宇樹推 22 自由度靈巧手 Dex5-S》同步顯示宇樹技術上**推 22 自由度靈巧手 Dex5-S**。

**核心訊號**:AI 消費端進入「**穿戴加速、機器人降速**」分歧期。**對台股的意義**:**大立光、聯亞、上詮**為 AI 眼鏡光學模組受惠暴增;**瑞昱、原相、聯詠**為 AI 眼鏡感測晶片受惠;**奇鋐、雙鴻、訊芯**為 AI 眼鏡/AR/VR 散熱與封裝受惠;**工具機族群** 日本加速帶動台廠工具機、**東台、亞崴、上銀**等同步受惠實體 AI 投資加速。

- **產能重分配成新常態**:台積 3/2 奈米在聯發科 TPU v9 觸發下正式鬆動,後續 AWS Trainium、Google TPU v9、AMD MI455X 都會比照,聯發科、世芯、創意等 ASIC 設計公司將陸續轉為「**產能觸發者**」,**台積電長約議價力**同步面臨結構性挑戰
- **HBM 戰場進入 IP 服務差異化**:GUC HBM4E IP 進入 SoIC-X 量產準備,把 HBM 從記憶體廠規格戰推進到 IP 設計服務商規格戰。**創意、世芯、智原、M31** 為台廠主要受惠者,SK 海力士與三星的垂直整合壓力同步升級

## 五、長期趨勢(半年~一年以上)

- **CoWoS-L + EMIB-T 雙軌封裝成形**:Google TPU v9 採用「前段台積 CoWoS-L + 後段 Intel EMIB-T」混合封裝,代表先進封裝從「單一生產線壟斷」演進為「**多生產線混搭**」,對台積、日月光、Amkor 同步是紅利,但對「誰能整合多封裝路線」的技術挑戰同步升級

- **Arm NB 統一戰線進入第二波**:Googlebook 5 機上市代表 Arm 陣營從「教育/低階」升級到「主流 NB 第二波統一」,聯發科、高通、英特爾、AMD 將在未來 2 年內繼續在 NB 戰場分化,**聯發科的天璣 CX C10 Max SoC** 為新一波

## 結論

本週中性偏多,核心訊號是**台積 3/2 奈米正式重分配給聯發科 TPU v9,產能配置從「台積分配給客戶」演進為「客戶觸發台積重配」**,這對聯發科、世芯、創意等 ASIC 族群是客戶角色升級的結構紅利,對台積電同步帶來產能利用率持續滿載的單價紅利,**短期單價紅利 vs 長約客戶結構調整風險同步升級**。

對台股供應鏈的具體動作方向:
- **核心受惠**:聯發科(客戶角色升級 + Googlebook 第一波 + A20 記憶體整合)、世芯、創意、智原(HBM4E IP 規格戰 + 客戶排程觸發)
- **卡位廠商**:京元電、矽格、穎崴、精測(GUC/聯發科後段封測);日月光投控(SoIC-X 先進封裝);長園科(AIDC 備援電力)
- **群組受惠**:ASIC 族群 + CoWoS/SoIC 設備族群 + Googlebook 概念股 + HBM4E IP 服務族群 + 綠電供應鏈
- **壓力受惠者**:記憶體 IP 服務在中國「雙龍頭之爭」壓力下需加速差異化
