**記憶體擴產軍備賽將進入「產能釋出 + 報價壓力」階段(2026 Q4 - 2027 Q1)**。SK 海力士 54 兆韓元(約 400 億美元)新建 2 座晶圓廠預計 2027 年下半年開始量產,屆時 HBM/DDR5 供給將進入「結構性釋出」階段,可能壓抑記憶體報價。但 AI 推論需求仍維持高成長(對 HBM 與 DDR5 拉貨穩定),中期供需平衡仍偏緊,記憶體漲價週期可望延續到 2027 Q2。同時南韓產業部長已示警長鑫存儲投資超越營收,中國記憶體國家隊將在 2026 Q4 - 2027 Q1 進入「產能釋出 + 削價競爭」新階段,三星 + SK 海力士 + 美光的全球 DRAM 份額可能從 95% 降到 85-88%。

**AI 推論雙引擎從「雲端」延伸到「軌道資料中心」(2026 Q4 - 2027 Q4)**。SpaceX Starmind AI1 預計 2027 年起全面採用 NVIDIA GPU 部署軌道 AI 資料中心,這是 AI 推論基礎設施的下一個結構性突破。預期 2027 年會有更多衛星/太空公司(SpaceX + Amazon Kuiper + 中國 GW + 歐盟 IRIS²)加入軌道 AI 賽局,台系 InP 雷射(聯亞、上詮、全新、IET-KY)、PCB 上游材料(台光電、聯茂、台燿、富喬)與衛星地面終端供應鏈將進入「雙引擎 + 軌道 AI」三軌拉貨期。

**中國 AI 國家隊進入「開源收費化 + 企業級商業化」雙軌並行(2026 Q4 - 2027 Q2)**。阿里 Qwen 擬對大用戶收費、Meta Muse Code 主攻企業開發者市場,代表「開源免費」神話結束,中國 AI 國家隊將從「開源普及 + 雲端補貼」走向「開源收費化 + 企業級商業化」雙軌制。台系 IC 設計(聯發科、創意、世芯-KY、M31、智原)、ASIC 服務商、AI 伺服器 ODM(廣達、緯創、緯穎、英業達)將同步受惠於中國 AI 國家隊對客製化晶片 + AI 伺服器的需求擴張,但「寒蟬效應分級」持續,雲端 AI 晶片仍受中國官方「自主發展」壓力,台廠需嚴陣以待。

**美國出口管制從「晶片」延伸到「光模組 + 上游材料」(2026 Q4 - 2027 Q4)**。FCC 擬禁中系光模組 + 川普多晶矽 15% 進口關稅,代表出口管制已從「半導體下游」擴張到「全太陽能 + 半導體上游材料」。聯亞(2026/07 月營收年增 1.76 倍)等台系光通訊廠將受惠於「美國客戶轉單效應」,矽晶圓廠(中美晶、環球晶)將受惠於「多晶矽價格下限 + 15% 進口關稅」,但需密切注意中國客戶轉單效應是否在 2027 年觸頂。

**南韓機器人國家隊成形,與中美形成三強並進(2026 Q4 - 2028)**。現代汽車(已納入 Boston Dynamics) + 樂金 + SK + 三星南韓四大集團共同布局機器人國家隊,2026/08/10 起具光謨訪矽谷會黃仁勳,樂金 x NVIDIA 機器人 + 智慧製造合作可望實質推進。中期南韓將與中美(中國宇樹 + 美國 Figure AI + Tesla Optimus)形成「人形機器人三強並進」新格局,台系機器人/自動化設備(和大、盟立、廣明、所羅門、原相、晶相光)與 ASIC 服務商(創意、世芯-KY、M31)同步受惠。

## 五、長期趨勢(半年 ~ 一年以上)

**AI 算力從「地面 + 雲端」走向「地面 + 雲端 + 軌道 + 終端」四軌並行(2027 - 2030)**。SpaceX Starmind AI1(軌道 AI 資料中心) + 緯創甲骨文大單(地面 AI 資料中心) + 聯電代工價起漲(成熟製程供應鏈) + 玻璃基板 TGV(次世代先進封裝) + 樂金 x NVIDIA 機器人(終端 AI),代表 AI 算力基礎設施進入「四軌並行」結構。預期 2027 - 2030 年 AI 算力將從「雲端集中」走向「分散式 + 軌道 + 終端」並行,台系 ODM(廣達、緯創、緯穎、英業達)、PCB 上游材料(台光電、聯茂、台燿、富喬)、InP 雷射(聯亞、上詮、全新、IET-KY)、矽光子(聯亞、上詮、IET-KY)、玻璃基板 TGV(閎康、友達、群創)將同步受惠於四軌並行新格局。

**記憶體國家隊三分天下(2027 - 2030)**。SK 海力士(HBM 領跑 + 54 兆韓元擴產) + 三星(2 奈米 + DRAM 龍頭) + 美光(DRAM/NAND 第三) + 長鑫存儲(中國國家隊,投資超前營收) + 台系記憶體(旺宏、華邦電、南亞科)+ 鴻海集團半導體版圖(天鈺、瑞鼎、樺漢)進入「五強並進 + 中國國家隊強攻」新格局。預期 2027 - 2030 年全球記憶體產業將從「三強(三星 + SK 海力士 + 美光)」走向「五強 + 中國國家隊」,台系記憶體廠在 NOR Flash + 利基型 DRAM 仍有差異化護城河,但 HBM 與高階 DDR5 將持續受制於 SK 海力士 + 三星 + 長鑫擠壓。

**美國出口管制從「晶片」走向「全太陽能 + 半導體供應鏈」(2027 - 2030)**。川普多晶矽 15% 進口關稅 + FCC 中系光模組禁令 + 上一階段的 BIS 對中出口管制 + Warren 聽證會 + 黃仁勳聽證會,代表美國對中國的「貿易戰 2.0」已擴張到「全太陽能 + 半導體 + 光通訊 + 上游材料」全面出口管制。預期 2027 - 2030 年台系光通訊廠(聯亞、上詮、IET-KY、全新)、矽晶圓(中美晶、環球晶)、太陽能(旭晶、綠能、聯合再生)、PCB 上游材料(台光電、聯茂、台燿、富喬)將持續受惠於「美國客戶轉單效應 + 中國客戶轉單台廠」雙軌並行。

**中國 AI 國家隊從「開源普及」走向「開源收費化 + 自主 ASIC」(2026 Q4 - 2030)**。阿里 Qwen 對大用戶收費 + Meta Muse Code 對決 OpenAI + Anthropic + 中國 CIS 自主化(三星 ISOCELL HPC 取代 Sony)+ 長鑫存儲投資超越營收 + 中國 AI 模型公司(阿里、字節、百度、騰訊)加速自研 ASIC,代表中國 AI 國家隊從「開源普及 + 雲端補貼」走向「開源收費化 + 自主 ASIC + 硬體自主化」三軌並行。台系 IC 設計(聯發科、創意、世芯-KY、M31、智原)需嚴陣以待「中國 ASIC 自主化」擠壓,但寒蟬效應分級 + 供應鏈分流成新常態,中期台廠在車用 + 週邊晶片 + 海外 CSP 客製化 ASIC 仍有結構性競爭優勢。
